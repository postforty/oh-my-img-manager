주요 기능 한눈에 보기

Oh My Image Manager는 웹 브라우저 내에서 100% 로컬(On-Device)로 작동하는 올인원 이미지 편집 확장 프로그램입니다. 외부 서버로 사진이 전송되지 않아 매우 안전하고 빠릅니다.

AI 스마트 누끼 스튜디오

최신 RMBG-1.4 모델로 원클릭 고화질 배경 제거, 스포이드 투명화 및 수동 리터치 브러시를 지원합니다.

대량 일괄 크롭 워크스페이스

수십 장의 이미지를 드래그 앤 드롭하여 동일한 여백/비율로 동시 크롭하고 ZIP으로 압축 다운로드합니다.

현재 탭 원클릭 캡처 & 크롭

브라우저에서 보고 있는 페이지 화면을 즉시 캡처하여 eBook 또는 지정된 비율로 자동 크롭 저장합니다.

스마트 배경 제거 (누끼) 스튜디오 사용법

단일 이미지를 정밀하게 편집하고 배경을 완벽하게 투명화할 수 있는 강력한 스튜디오입니다.

1. 이미지 불러오기

  • 드래그 앤 드롭: 이미지 파일을 캔버스 영역으로 끌어다 놓습니다.
  • 클립보드 붙여넣기: 캡처 도구나 웹에서 복사한 이미지를 Ctrl + V 로 즉시 붙여넣을 수 있습니다.
  • 파일 선택: [파일 선택하기] 버튼을 눌러 로컬 이미지를 불러옵니다.

2. AI 원클릭 배경 제거 (추천)

온디바이스 SOTA AI 모델 (RMBG-1.4) 탑재
  • 좌측 패널 상단의 [원클릭 AI 배경 제거] 버튼을 누르면 인물, 사물, 제품의 경계선을 정밀 분석하여 배경을 자동으로 깔끔하게 지워줍니다.
  • WebGPU 가속: 지원되는 브라우저 환경에서 고성능 GPU 가속을 통해 수초 내에 초고속으로 처리됩니다. (미지원 환경에서는 안정적인 WASM 모드로 자동 전환)

3. 단색 / 스포이드 지우개

  • 스포이드 선택: 이미지에서 제거하고 싶은 특정 배경색(예: 흰색 스튜디오 배경, 크로마키 녹색 등)을 마우스로 클릭하여 지정합니다.
  • 허용 오차 (Tolerance): 지정한 색상과 비슷한 색상을 어디까지 투명화할지 범위를 조절합니다.
  • 가장자리 부드럽게 (Feather): 경계선이 거칠지 않도록 부드러운 블러 페더링을 적용합니다.
  • 선택 색상 투명화 적용: 버튼을 누르면 해당 색상이 즉시 투명해집니다.

4. 수동 리터칭 브러시

  • 지우개: 덜 지워진 잔여물이나 불필요한 영역을 마우스로 문질러 추가로 지웁니다.
  • 복원 펜: 너무 많이 지워진 원본 영역을 마우스로 문질러 다시 되살려냅니다.
  • 브러시 크기 & 경계 부드러움: 정밀한 다듬기를 위해 슬라이더로 조절하거나 단축키 [, ] 를 사용하세요.

5. 배경 채우기 & 비교 뷰어

  • 배경 채우기: 투명 체커보드 외에 [화이트], [블랙], [컬러(단색)]를 선택하여 합성 결과를 미리 검토할 수 있습니다.
  • 비교 뷰어 탭:
    • 투명 결과물: 현재 완성된 투명 배경 결과물을 확인합니다.
    • 원본 보기: 편집 전 원본 이미지를 빠르게 확인합니다.
    • 좌우 비교 분할: 슬라이더를 마우스로 드래그하여 원본과 결과물을 실시간 분할 비교합니다.

6. 내보내기 및 복사

  • 투명 PNG 다운로드: 고해상도 투명 PNG 파일로 컴퓨터에 저장합니다.
  • 클립보드로 복사 (Ctrl + C): 포토샵, 피그마, 파워포인트, 메신저 등에 바로 붙여넣을 수 있도록 클립보드에 복사합니다.

대량 일괄 크롭 워크스페이스 사용법

웹툰, 전자책(eBook), 스캔 문서, 상품 사진 등 수십~수백 장의 이미지를 같은 비율로 균일하게 자를 때 사용합니다.

대량 처리 워크플로우
  1. 다수의 이미지 파일을 화면에 드래그 앤 드롭하여 큐(대기열)에 등록합니다.
  2. 좌측 패널에서 크롭 프리셋(eBook 상/하단 여백 제거, 1:1, 4:3, 16:9 등)을 선택하거나 상/하/좌/우 슬라이더로 영역을 맞춥니다.
  3. 우측 상단의 [영역 표시 가이드] 탭에서 잘릴 영역(빨간 점선)을 확인하고, [크롭 결과물] 탭에서 미리보기 합니다.
  4. 대기열에서 썸네일을 클릭하면 다른 이미지의 크롭 상태도 실시간으로 확인할 수 있습니다.
  5. [일괄 크롭 & ZIP 다운로드] 버튼을 누르면 순식간에 모든 이미지가 크롭되어 압축 파일(.zip)로 저장됩니다.

현재 웹 탭 캡처 & 자동 크롭

브라우저 툴바의 Oh My Image Manager 확장 프로그램 아이콘을 클릭한 뒤 [현재 웹 탭 캡처 & 자동 크롭] 버튼을 누르면, 브라우저에 표시된 화면을 즉시 캡처하여 상하 여백을 깔끔하게 제거한 뒤 바로 다운로드합니다.

유용한 단축키 안내

단축키 기능 설명
Ctrl + V 클립보드에 저장된 이미지를 스튜디오 캔버스에 즉시 불러오기
Ctrl + C 현재 편집 중인 투명 배경 이미지를 클립보드로 복사하기
Ctrl + Z 이전 작업 단계로 되돌리기 (Undo)
Ctrl + Y / Ctrl + Shift + Z 되돌린 작업 다시 실행하기 (Redo)
[ / ] 리터칭 브러시 크기 줄이기 / 늘리기

완벽한 데이터 보안

Oh My Image Manager의 모든 기능(AI 배경 제거, 이미지 크롭, 브러시 편집, ZIP 압축 등)은 사용자의 PC 웹 브라우저 내부에서만 온디바이스로 처리됩니다. 업로드하는 이미지는 외부 서버로 절대 전송되지 않으므로, 중요한 개인 정보나 업무용 보안 이미지를 안심하고 편집하실 수 있습니다.
